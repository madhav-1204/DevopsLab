Experiment 10: Install and Explore Selenium for Automated Testing
Aim: To install Selenium WebDriver and explore automated browser testing.
Procedure
1. Install Node.js and npm.
2. Create a project folder named SeleniumLab.
3. Initialize the Node.js project:
   npm init -y
4. Install Selenium WebDriver:
   npm install selenium-webdriver
5. Create a JavaScript file named test.js.
6. Write the Selenium script to open Chrome and perform a Google search.
7. Execute the script:
   node test.js
8. Observe the browser automation and check the page title in the terminal.
Result
Selenium WebDriver was installed successfully and used to automate browser actions and retrieve the webpage title.
