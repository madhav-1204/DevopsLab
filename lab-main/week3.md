Aim
To push and manage source code using GitHub.
Procedure
1. Create a GitHub account.
2. Create a new repository on GitHub.
3. Clone the repository.
git clone <repository-url>


4. Open the repository folder.
cd <repository-name>


5. Create a file named index.html and write your Experiment 1 code.
6. Add the file.
git add index.html


7. Commit the changes.
git commit -m "Added registration form"


8. Push the code to GitHub.
git push origin master


Simple explanation
Command	Purpose
git clone	Downloads the repository
cd	Opens the project directory in the terminal
git add	Stages the file
git commit	Saves the changes in Git history
git push	Uploads commits to GitHub

Expected output: Your index.html file appears in your GitHub repository.
