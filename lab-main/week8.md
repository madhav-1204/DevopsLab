Brief points for your lab record
Aim: To enable Kubernetes on Docker Desktop and prepare the system to run Kubernetes commands.
Procedure
1. Start Docker Desktop.
2. Open Settings and select Kubernetes.
3. Create and activate a Kubernetes cluster.
4. Open Command Prompt or the VS Code terminal.
5. Check the Kubernetes client version:
   kubectl version --client
6. Display the pods:
   kubectl get pods
7. Display the cluster nodes:
   kubectl get nodes
8. Display cluster information:
   kubectl cluster-info
Result
Kubernetes was successfully enabled in Docker Desktop, and Kubernetes commands were executed to verify the cluster and its resources. 8th Program (2).pdf
