Aim: To test a JavaScript registration form using Selenium WebDriver.

Procedure:
1. Create a registration form using HTML and JavaScript.
2. Start the local server using npx http-server.
3. Install Selenium using npm install selenium-webdriver.
4. Create test.js to automate form filling and submission.
5. Run the test using node test.js.
6. Verify the success message in the terminal.
Result: The registration form was successfully tested using Selenium WebDriver, and the output displayed Registration Successful! and Test Passed.
